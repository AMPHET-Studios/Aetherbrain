# Evergreen Notes

A term I picked up from [[Andy Matuschak]]'s public working notes: notes written to evolve and accumulate value over years, rather than to capture something once and be forgotten. His guidelines, paraphrased:

- Notes should be atomic — see [[Zettelkasten#Atomicity]]
- Notes should be concept-oriented, not organized by source or book
- Notes should be densely linked
- Prefer associative structure over hierarchical taxonomies
- Write notes for yourself by default

## Note lifecycle in this vault
| Stage | Status value | Typical lifespan | Example |
|---|---|---|---|
| Fleeting | `unprocessed` | days | inbox captures |
| Seedling | `seedling` | weeks | a half-formed idea with one link |
| Budding | `budding` | months | has a claim, some links, gaps |
| Evergreen | `evergreen` | years | stable, dense, reused often |

## Titles as claims
An evergreen title is either a crisp concept name or a claim, so it can be dropped into a sentence like a building block. "Value is the skeleton of a painting" beats "Notes on value".

## Keeping them green
Revisiting is what keeps them alive — the same insight behind [[Spaced Repetition]] and [[Progressive Summarization]]. [[Aether Brain]] could make neglect visible; see [[Idea - Neurons that decay without review]].
