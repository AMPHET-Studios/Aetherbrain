# Value Structure

Value — how light or dark something is — carries most of what makes an image read. Color gets the compliments; value does the work. If a piece reads in grayscale, color can only help it.

## Three-Value Rule
Organize the whole image into three main groups — light, middle, dark — before rendering anything. Each group should be a big connected shape, not confetti. Then:
- Put the strongest contrast at the focal point
- Keep secondary areas inside one group
- Add a fourth value (an accent) only if it earns its place

## Squint Test
Squint until the detail blurs out. What remains is the value structure. If the focal point disappears, or everything melts into mid-gray, no amount of rendering will fix it. Digital version: shrink the canvas to thumbnail size and desaturate.

## Common failures
- Mid-gray soup: everything within a narrow range
- Busy darks: shadows full of small light shapes
- Competing lights at the edges pulling the eye out of frame

## Bridges
- [[Composition]] decides *where*; value decides *what the eye sees first*
- [[Color and Light]] builds on top — temperature shifts happen within a value group
- [[Silhouette Design]] is value structure at its most extreme: two values
- In real-time graphics, glow only reads if the frame leaves dark headroom — [[Bloom Post-Processing]] is a value decision
