# Reference Hub Rules

How the reference viewer in [[ConceptForge]] is meant to be used.

- **Grayscale first:** read the value pattern before the color distracts ([[Value Structure]])
- **Flip often:** a horizontal flip exposes drawing errors the eye has learned to ignore
- **Grid for perspective:** switch on the 2-point overlay only to check, never to trace ([[Perspective Fundamentals]])
- **Color last:** study light temperature in the reference before choosing a palette ([[Color and Light]])
- Only my own photos or public-domain images; every image keeps a note of where it came from
