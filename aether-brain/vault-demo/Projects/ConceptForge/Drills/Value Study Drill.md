# Value Study Drill

The ConceptForge value drill: ten minutes, three values, one reference. Part of [[ConceptForge]].

- Timer: 10 min, the value ramp overlay locked to three steps ([[Value Structure]])
- Start with the largest shadow shape, then the lights; mid-gray is whatever is left
- Grader checks value range and how many of the three groups actually appear
- Pass mark: the study still reads when shrunk to a 64 px thumbnail
