# Portal Game Vertical Slice

Working title: **Verdant Gate**. An ancient high-tech, sci-fi dark fantasy game set in rainforest ruins. A lost civilization left stone machines that still hum under the moss — and one portal that might still open.

## Pillars
1. **Awe** — monumental scale, humid light, the [[Ancient High-Tech Aesthetic]]
2. **Discovery** — the ruins explain themselves through [[Environmental Storytelling]], not text dumps
3. **Weight** — the portal must *feel* powerful; see [[Game Feel]]

## Scope
One level, 15–20 minutes of play. The player crosses an overgrown terrace, restores power to the [[Monolith Generator Asset]], and opens the gate.

- In scope: traversal, one puzzle chain, one portal transition
- Out of scope: combat, inventory, saving, menus beyond pause
