# PORTALz

> The portal game, whole. Ancient high-tech sci-fi dark fantasy: stone machines humming under rainforest moss, one gate that might still open, and a small robot companion that has waited a very long time. Built in Unreal Engine 5.

This board is the umbrella; the playable proof is the [[Portal Game Vertical Slice]] (working title *Verdant Gate*). Everything here should push that slice toward "whoa".

## Pillars
1. **Awe** — monumental scale and humid light; the [[Ancient High-Tech Aesthetic]]
2. **Discovery** — ruins that explain themselves through [[Environmental Storytelling]]
3. **Weight** — the portal must *feel* powerful; [[Game Feel]] is a feature
