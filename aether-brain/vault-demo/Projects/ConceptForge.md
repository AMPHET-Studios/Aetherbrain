# ConceptForge

> A pressure-sensitive concept-art trainer built for the XP-Pen Artist 24 Pro 4K: timed drills, overlays, a reference hub, a drawing library, and a grader that tells me where to improve. One HTML file, runs offline, no account.

The trainer exists because [[Deliberate Practice]] needs three things a sketchbook doesn't give me: a clock, a rubric, and a record. It feeds the [[Concept Art Portfolio 2026]] directly — every drill is a warm-up for a real piece.

## What it does
- **Drills** — Warm-Up, Gesture (30 s poses, see [[Gesture Drawing]]), Form & Volume, Value Study ([[Value Structure]]), Silhouette ([[Silhouette Design]]), Perspective ([[Perspective Fundamentals]]), Thumbnail Comps ([[Thumbnailing]]), Free Canvas
- **Overlays** — 1- and 2-point grids, value ramp, thumbnail boxes, rule of thirds, symmetry mirror
- **Reference Hub** — my own images in a floating viewer (opacity, grid, flip, grayscale), random CC0 photos, 40+ curated links
- **Library** — 15 distilled fundamentals chapters, each ending in a drill
- **Grade Work** — offline image analysis: completion, value range, value structure, [[Composition|composition]], edge variety, line economy, reference match
- **Deep Critique** — optional bring-your-own-key vision model for anatomy and design feedback

## Notes

Graded drawings land in the Critique planet as a picture plus a note (the latest: [[2026-09-28 Value Study|a value study]], whose top fix is already on the brief).

The grader is heuristics, not a neural net, and that is fine: it is consistent, instant and honest about what it can't judge. What it *can't* see — anatomy, likeness, story — is exactly what [[Spaced Repetition|spaced review]] of my own old drills is for. Practice logs live in [[Creative Practice]].
