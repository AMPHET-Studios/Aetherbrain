# Question - Can value studies be graded automatically

Could a small script score my value studies? Rough approach:

- Convert to grayscale and posterize to three or four levels
- Measure how much of the frame each value group covers
- Check whether the strongest contrast sits near the intended focal point
- Flag muddy studies where the middle grays eat more than 70% of the image

Risk: it would reward formula over intent. Maybe useful as a warm-up checker, never as a judge. #idea
